# Integration metadata

- [`../server.json`](../server.json) describes the npm and hosted Streamable
  HTTP connection options for MCP registries.
- [`../docker-mcp-catalog.yaml`](../docker-mcp-catalog.yaml) contains the
  reviewed server metadata for the Docker MCP Catalog contribution.
- `github-topics.txt` contains the repository's public discovery topics.

These files contain no credentials. Their versioned fields match the npm package
and MCPB manifest.
